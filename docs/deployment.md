# Deployment

## Objetivo

Preparar una guia base de despliegue sin activar nada real.

## Candidatos

- frontend: `Vercel`
- backend: `Render` o infraestructura equivalente
- base de datos: `Supabase`
- automatizacion: `n8n`

## Regla

- no hacer deploy sin confirmacion;
- documentar variables necesarias en `.env.example` e `integrations/`.
