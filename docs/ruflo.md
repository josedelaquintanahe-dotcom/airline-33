# Ruflo - Airline 33

## Objetivo

Usar Ruflo como capa externa de coordinacion para que el proyecto mantenga continuidad sin perder foco comercial ni documental.

## Funcion

Ruflo ayuda a:

- coordinar bloques
- mantener memoria operativa
- repartir tareas entre agentes
- sostener continuidad entre sesiones
- reforzar trazabilidad

## Limite

Ruflo no define la marca ni sustituye criterio creativo. Debe obedecer `context.md`, `CODEX.md` y `AGENTS.md`.

## Regla de negocio

Toda orquestacion debe empujar al mismo objetivo: vender un drop pequeno y coherente, aprender y escalar con orden.
