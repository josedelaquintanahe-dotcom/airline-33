# Milestone 2 Execution Checklist - Airline 33

## Objetivo

Pasar de preparacion documental a ejecucion real de `Shopify + Drop 001 + reactivacion de Instagram`.

## Bloque 1 - Propiedad y dominio

- cuenta propietaria definida
- `2FA` activa
- dominio confirmado
- acceso al registrador verificado

## Bloque 2 - Shopify

- tienda creada
- moneda y mercado base configurados
- navegacion minima creada
- politicas visibles
- captura de email visible

## Bloque 3 - Catalogo

- productos creados
- variantes cargadas
- stock por SKU cargado
- imagenes subidas
- copy revisado

## Bloque 4 - Logistica

- origen de envio definido
- tarifas base configuradas
- politica de devolucion visible
- criterio de embalaje definido

## Bloque 5 - Reactivacion de Instagram

- bio actualizada
- link principal configurado
- primeros posts definidos
- calendario corto validado

## Bloque 6 - Automatizacion minima

- flujo de lead documentado
- flujo de pedido documentado
- alerta de stock bajo documentada
- prueba en entorno controlado pendiente de ejecucion

## Criterio de cierre

El milestone queda listo para ejecucion real cuando el equipo solo tenga que configurar, cargar y probar, no volver a decidir la estructura.
