# Ruflo - Airline 33

## Objetivo

Esta carpeta documenta como se usa Ruflo en Airline 33.

## Papel de Ruflo

Ruflo debe actuar como capa de coordinacion de agentes, no como sustituto del criterio estrategico.

Debe ayudar a:

- orquestar agentes;
- mantener memoria operativa;
- ejecutar workflows;
- revisar tareas;
- coordinar desarrollo;
- documentar decisiones;
- evitar perdida de contexto.

## Regla

Antes de usar Ruflo en una tarea, comprobar que la tarea tiene relacion directa con:

- marca
- producto
- ecommerce
- backend
- base de datos
- automatizacion
- ventas
- seguridad
- despliegue
