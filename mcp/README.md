# MCP - Airline 33

## Objetivo

Esta carpeta documenta las conexiones MCP de Airline 33.

## Para que se usa MCP

MCP permite que agentes y herramientas accedan de forma controlada a sistemas externos o locales.

## Conexiones objetivo

- Ruflo
- Filesystem
- GitHub
- Supabase
- n8n
- Browser
- herramientas futuras justificadas

## Regla principal

Una conexion MCP solo debe añadirse si mejora la capacidad de construir, operar o vender Airline 33.

## Seguridad

Nunca documentar claves reales. Usar `.env` local y `.env.example` como plantilla.
